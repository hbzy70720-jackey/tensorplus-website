# 英文版国际化（i18n）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有中文官网 www.tensorplus.cn 上新增英文版（`/en/*` 前缀），默认中文、右上角「中文 / EN」切换，内容与中文版一致（整句意译）。

**Architecture:** App Router 用 `[lang]` 段承载公共页面 + `middleware.ts` 解析 locale（无前缀 rewrite 到 `/zh`，`/en/*` 直通）；静态文案走自建词典（`lib/i18n`），案例动态内容在 `CaseStudy` 表加英文字段（未填回退中文）；根布局通过 middleware 注入的 `x-locale` header 动态设置 `<html lang>` 与 metadata。

**Tech Stack:** Next.js 16 App Router、React 19、Prisma(SQLite)、Tailwind CSS 4、TypeScript。

**Spec:** `docs/superpowers/specs/2026-10-11-english-i18n-design.md`

## Global Constraints

- 交互/回复/注释/文档用中文；代码命名（变量/函数/组件/字典 key）用英文。
- 默认语言 `zh`，访问根路径不自动跳转；英文仅通过 `/en` 前缀 + 切换器进入。
- 公司英文全称：`Beijing TensorPlus Technology Co., Ltd.`
- 翻译为整句意译，术语以 `lib/i18n` 术语表为准；全部英文文案完成后一次性交用户 review。
- 后台 `/admin` 与 `/api` 不参与 locale，保持中文（仅案例表单加英文输入区）。
- 案例英文字段未填时回退中文，不允许渲染空/`null`。
- 不自动 `git push`；每个 task 完成后本地 `git commit`，push 需用户确认。
- 无测试框架（package.json 无 jest/vitest），验证用 `npm run build` + `npm run lint` + 浏览器手动核对。

## Review Focus

以下 6 类输入/失败模式最容易咬到使用者，逐一在对应 task 里用「验证步骤」钉住：

1. **middleware 误 rewrite 排除路径**：`/admin`、`/api`、`/_next`、带扩展名的静态资源若被 rewrite，后台登录、接口、图片会 404 → Task 3。
2. **内部链接未 locale 化**：英文页内点 `href="/about"` 会跳回中文页，应指向 `/en/about` → Task 4/6/7/8 全程。
3. **`usePathname()` 在 middleware rewrite 后的返回值**：可能是原始路径 `/about` 也可能是 `/zh/about`，影响 `isDarkPage` 黑底判断与切换器路径映射 → Task 3/4。
4. **案例英文字段缺失回退**：旧案例无 `titleEn` 时，`/en/cases/[slug]` 必须回退中文标题而非空白 → Task 8。
5. **industry 筛选值与显示标签分离**：query 仍用 canonical 中文值（`industry=光伏`），英文页按钮显示「Solar」但筛选逻辑不变 → Task 8。
6. **hreflang / canonical 正确**：`/en/about` 的 canonical 指向 `https://www.tensorplus.cn/en/about`，alternate 指向 `/about`，无双重前缀 → Task 10。

- [ ] **Step 1: 写 `middleware.ts`**

```ts
import { NextRequest, NextResponse } from "next/server";

const EXCLUDED = /^\/(admin|api|_next)(\/|$)|\./;

export function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;
  const isEn = pathname === "/en" || pathname.startsWith("/en/");
  const locale = isEn ? "en" : "zh";

  const headers = new Headers(request.headers);
  headers.set("x-locale", locale);

  // 排除路径与 /en/* 直接放行；其余无前缀路径 rewrite 到 /zh/*
  if (EXCLUDED.test(pathname) || isEn) {
    return NextResponse.next({ request: { headers } });
  }

  const url = request.nextUrl.clone();
  url.pathname = "/zh" + (pathname === "/" ? "" : pathname);
  return NextResponse.rewrite(url, { request: { headers } });
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico|images/).*)"],
};
```

- [ ] **Step 1: 写 `lib/locale-link.ts`**

```ts
import type { Locale } from "@/lib/i18n/config";

// 去掉路径开头的 /en 前缀（若有），得到不带 locale 的路径
export function stripLocalePrefix(pathname: string): string {
  if (pathname === "/en") return "/";
  if (pathname.startsWith("/en/")) return pathname.slice(3) || "/";
  if (pathname === "/zh") return "/";
  if (pathname.startsWith("/zh/")) return pathname.slice(3) || "/";
  return pathname;
}

// 生成目标语言的同页路径
export function localizePath(pathname: string, targetLang: Locale): string {
  const base = stripLocalePrefix(pathname);
  if (targetLang === "en") return base === "/" ? "/en" : `/en${base}`;
  return base;
}

// 生成目标语言下的站内链接（给 <Link href> 用）
export function localizedHref(href: string, lang: Locale): string {
  if (href.startsWith("http") || href.startsWith("mailto") || href.startsWith("#")) return href;
  return lang === "en" ? (href === "/" ? "/en" : `/en${href}`) : href;
}
```

"use client";
import { useEffect, useRef, useState } from "react";
import Link from "next/link";
import { usePathname } from "next/navigation";
import { Globe, ChevronDown } from "lucide-react";
import { locales, type Locale, localeNames } from "@/lib/i18n/config";
import { useLocale } from "@/lib/i18n";
import { localizePath } from "@/lib/locale-link";
import { cn } from "@/lib/utils";

export default function LanguageSwitcher({ dark = false }: { dark?: boolean }) {
  const pathname = usePathname();
  const currentLang = useLocale();
  const [open, setOpen] = useState(false);
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const onClick = (e: MouseEvent) => {
      if (ref.current && !ref.current.contains(e.target as Node)) setOpen(false);
    };
    document.addEventListener("mousedown", onClick);
    return () => document.removeEventListener("mousedown", onClick);
  }, []);

  useEffect(() => setOpen(false), [pathname]);

  return (
    <div ref={ref} className="relative">
      <button
        type="button"
        onClick={() => setOpen((v) => !v)}
        aria-haspopup="menu"
        aria-expanded={open}
        className={cn(
          "inline-flex items-center gap-1.5 rounded-lg px-3 py-2 text-sm font-medium transition-colors",
          dark ? "text-gray-300 hover:text-white" : "text-[var(--text-muted)] hover:text-[var(--text-dark)]"
        )}
      >
        <Globe className="h-4 w-4" />
        {localeNames[currentLang]}
        <ChevronDown className={cn("h-3.5 w-3.5 transition-transform", open && "rotate-180")} />
      </button>
      {open && (
        <div className="absolute right-0 top-full z-50 mt-2 min-w-[140px] overflow-hidden rounded-xl border border-gray-100 bg-white py-1 shadow-lg">
          {locales.map((lang: Locale) => (
            <Link
              key={lang}
              href={localizePath(pathname, lang)}
              className={cn(
                "block px-4 py-2 text-sm transition-colors",
                lang === currentLang ? "bg-gray-50 font-medium text-[var(--accent)]" : "text-[var(--text-muted)] hover:bg-gray-50 hover:text-[var(--text-dark)]"
              )}
            >
              {localeNames[lang]}
            </Link>
          ))}
        </div>
      )}
    </div>
  );
}

- [ ] **Step 1: 各 page `generateMetadata` 增加语言与 alternates**

以 `cases/[slug]` 为例：

```ts
export async function generateMetadata({ params }: PageProps): Promise<Metadata> {
  const { lang, slug } = await params;
  const isEn = lang === "en";
  const caseStudy = await prisma.caseStudy.findUnique({ where: { slug, published: true } });
  if (!caseStudy) return { title: "Case not found" };
  const title = isEn ? caseStudy.titleEn || caseStudy.title : caseStudy.title;
  const base = "https://www.tensorplus.cn";
  const path = `/cases/${slug}`;
  return {
    title,
    description: (isEn ? caseStudy.descriptionEn : caseStudy.description) || title,
    alternates: {
      canonical: `${base}${isEn ? "/en" + path : path}`,
      languages: { "zh-CN": `${base}${path}`, en: `${base}/en${path}` },
    },
    openGraph: { locale: isEn ? "en_US" : "zh_CN", url: `${base}${isEn ? "/en" + path : path}` },
  };
}
```

其余静态页面（about/contact/3d-perception/robot/首页）同理，用 `getDictionary(lang)` 提供英文 title/description。
