# 网站图片存放指南

## 目录结构

将所有图片放入 `public/images/` 对应子目录：

```
public/
└── images/
    ├── perception/          ← 3D感知方案页面的场景图片
    │   ├── pv-1.jpg        ← 光伏组件检测 图1
    │   ├── pv-2.jpg        ← 光伏组件检测 图2
    │   ├── pv-3.jpg        ← 光伏组件检测 图3
    │   ├── log-1.jpg       ← 原木测量与分拣 图1
    │   ├── log-2.jpg       ← 原木测量与分拣 图2
    │   ├── log-3.jpg       ← 原木测量与分拣 图3
    │   ├── power-1.jpg     ← 石油、电力巡检 图1
    │   ├── power-2.jpg     ← 石油、电力巡检 图2
    │   └── power-3.jpg     ← 石油、电力巡检 图3
    │
    └── robot/              ← 全地形机器人页面的场景图片
        ├── agri-1.jpg      ← 农业自动化 图1
        ├── agri-2.jpg      ← 农业自动化 图2
        ├── agri-3.jpg      ← 农业自动化 图3
        ├── forest-1.jpg    ← 林业巡护 图1
        ├── forest-2.jpg    ← 林业巡护 图2
        ├── forest-3.jpg    ← 林业巡护 图3
        ├── oil-1.jpg       ← 石油、电力巡检 图1
        ├── oil-2.jpg       ← 石油、电力巡检 图2
        └── oil-3.jpg       ← 石油、电力巡检 图3
```

## 图片要求

- **格式**: JPG（推荐）或 WebP
- **尺寸建议**: 1200×800 像素（16:10 左右比例）
- **单张大小**: 建议不超过 500KB，可用 TinyPNG 等工具压缩
- **内容**: 对应场景的实拍照片或效果图

## 功能说明

- 每个场景支持多张图片（1~N 张），图片正下方有小圆点导航
- 点击左右箭头或小圆点可切换图片
- 键盘左右方向键也可切换
- 如果某场景未放图片，会显示"暂无图片"占位
- 图片懒加载：仅首张立即加载，其余按需加载

## 快速验证

1. 放入图片后，启动开发服务器 `npm run dev`
2. 访问 `http://localhost:3000/3d-perception` 查看 3D 感知方案页
3. 访问 `http://localhost:3000/robot` 查看全地形机器人页
4. 每个场景应展示图片轮播效果
